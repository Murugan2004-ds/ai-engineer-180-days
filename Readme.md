## 💡 Rules to Live By

1. **No zero days.** Even 30 min of work is a win.
2. **Commit daily.** Your GitHub graph is your proof.
3. **Write it down.** If you can't explain it, you didn't learn it.
4. **Build > Watch.** Tutorials are a starting point, not the goal.
5. **Iterate.** You will revisit old projects — that's growth.
6. **Ask why.** Understanding beats memorization.
7. **Finish.** A shipped project teaches more than 10 unfinished ones.
